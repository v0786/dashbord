# Webdev workspace

A fresh Next.js recreation of the Webdev dashboard reference with an animated login/signup inspired by the supplied video.

Run `npm run dev` and visit http://localhost:3000. Dashboard: `/`. Animated login: `/login`. Signup: `/signup`.

Includes project creation and JSON import, a draggable task board, stage changes and filters, calendar navigation, analytics period selection and CSV export, member creation and profiles, local messages, timer, demo meetings, profile settings, notification preferences, dark mode and compact layout. Data persists in browser localStorage.

This is a frontend demo. Authentication accepts any username and a password of at least 8 characters. It does not store passwords or provide production authentication, email delivery, external chat, video conferencing, or native mobile apps.

Previous project source was removed from the active project and archived at `/tmp/fernly-previous-source.tar.gz` for recovery.
